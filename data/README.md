# Dataset access

The raw datasets are intentionally **not included** in this public repository. The research used publicly available social-media datasets obtained through Kaggle.

See the dataset details and licensing terms before downloading or redistributing source data: https://www.kaggle.com/datasets/saurabhshahane/cyberbullying-dataset

The training notebook expects the dataset files referenced in its data-loading cell. Run the notebook in Google Colab and upload permitted dataset files when prompted.
